# Лабораторная работа №3. Веб-приложение на Express.js и EJS

Система управления учебными курсами: просмотр, добавление, редактирование и удаление курсов,
поиск, фильтрация по семестру, валидация форм. Архитектура MVC, шаблоны EJS.
Данные хранятся в массиве в памяти, после перезапуска сервера они возвращаются к исходным.

**Автор:** Иордатий Игнат, группа IA2403

## Технологии

- Node.js
- Express.js 5
- EJS (шаблонизатор)

## Установка и запуск

```bash
npm install
npm start
```

Приложение доступно по адресу `http://localhost:3000`.

## Маршруты

| Метод | URL | Назначение |
|---|---|---|
| GET | `/` | перенаправление на `/courses` |
| GET | `/courses` | список курсов (поддерживает `search` и `semester`) |
| GET | `/courses/new` | форма добавления |
| POST | `/courses` | сохранение нового курса |
| GET | `/courses/:id` | просмотр курса |
| GET | `/courses/:id/edit` | форма редактирования |
| POST | `/courses/:id/edit` | сохранение изменений |
| POST | `/courses/:id/delete` | удаление курса |

## Поиск и фильтрация

```
GET /courses?search=ivan
GET /courses?semester=1
GET /courses?search=node&semester=3
```

Поиск идёт по названию и преподавателю без учёта регистра. Параметры можно комбинировать.

## Валидация

Middleware `validateCourse` проверяет: название, преподаватель и описание заполнены;
кредиты это положительное число; семестр это целое число от 1 до 8.
При ошибке курс не сохраняется, форма возвращается с сообщениями и введёнными данными.

## Middleware

- `logger` выводит в терминал `METHOD | URL | DD.MM.YYYY HH:MM` для каждого запроса;
- `express.urlencoded` разбирает данные HTML-форм;
- `express.static` отдаёт CSS из папки `public`;
- обработчики 404 и внутренних ошибок (без вывода stack trace пользователю).

## Страницы ошибок

- `404.ejs`: неизвестный маршрут или несуществующий курс (код, сообщение, запрошенный URL, ссылка на список);
- `error.ejs`: внутренняя ошибка сервера (код 500).
